# Code of conduct

Statespace welcomes contributors with different backgrounds and levels of experience.

Be respectful, direct, and constructive. Discuss technical decisions without personal attacks. Do not harass, threaten, discriminate against, or expose private information about another person.

Maintainers can edit or remove harmful content. They can restrict participation when conduct harms contributors or the project.

Report conduct problems privately to the repository maintainers. Do not use a public issue for a sensitive report.
