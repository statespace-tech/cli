# Changelog

This repository records notable CLI changes. Releases use semantic versioning.

## Unreleased

### Changed

- Print command results as JSON.
- Create and publish immutable experiment versions from YAML.
- Manage SDK and CI tokens through `ssp token`.
- Manage read-only PostgreSQL credentials through `ssp database credential`.
- Query the account PostgreSQL database through `ssp query`.

## 0.1.0 - 2026-09-01

### Added

- The `ssp` binary.
- Browser login with GitHub or Google.
- Account, token, and experiment commands.
- Portable Linux and native macOS release binaries.
